# Notebooks

This folder is reserved for exploratory data analysis (EDA), prototyping, and experiment notebooks.

## Guidelines

- Prefer reproducible scripts under `src/` for final pipeline stages.
- Keep notebooks lightweight and well-named (e.g., `01_eda_prices.ipynb`).
- Do not commit large intermediate outputs or embedded datasets.
